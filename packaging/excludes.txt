# PyInstaller's modulegraph follows guarded/optional imports (`try: import X`)
# whether or not they can ever run, so every unrelated package installed
# alongside the app gets walked. That is what made Analysis run past 30 minutes.

# minus every declared transitive dependency of that closure. The dependency walk
# is required -- torch imports sympy/jinja2/filelock/fsspec lazily, so they are
# absent from a plain import closure but needed at runtime.
#
# Regenerate after changing dependencies; a stale entry here shows up as an
