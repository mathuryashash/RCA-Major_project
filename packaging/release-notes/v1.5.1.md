LocalRCA records what your computer is doing, learns what normal looks like for
*your* machine, and afterwards tries to explain a slowdown, stall or crash. It
runs entirely on the endpoint. Nothing collected is ever uploaded, and the
collector opens no sockets. The only network capability is an opt-in check for
a newer release, off until you turn it on, which reads a version number and
sends nothing.

## Before you download

**Windows will still warn you.** This build is signed with a self-signed
certificate, which proves the exe wasn't tampered with between build and your
download, but does not clear the SmartScreen "Windows protected your PC"
warning — that requires a certificate from a CA Microsoft trusts, which costs
money this project doesn't spend. Click **More info → Run anyway** if you
trust the source, or verify the checksum below and build from source instead.

**It needs about a day before it is useful.** Roughly 21 hours of clean
collection are required before there is enough baseline to train a model.
Until then the app runs and shows what it has captured, but cannot analyse
anything.

## Install

1. Download `LocalRCA-v1.5.1-windows-x64.zip`.
2. **Verify it** — in PowerShell:
   ```powershell
   Get-FileHash LocalRCA-v1.5.1-windows-x64.zip -Algorithm SHA256
   ```
   Expected:
   ```
   3848E6BF6EEB906D2DBE3265D7FDAC40190AE967E19191575EA8049BF88C55B5
   ```
3. Extract the **whole** ZIP somewhere you can write to, e.g. `C:\LocalRCA`.
   Do not run it from inside the archive — it needs the files beside it.
4. Run `RCA-Desktop\RCA-Desktop.exe`.
5. Read the consent dialog and agree, or decline and nothing is collected.

No administrator rights are used and nothing is written outside your own user
profile.

## What's new in 1.5.1

- **Simple / Advanced view split.** The app now opens in a simplified view by
  default: a single colour-coded status sentence instead of a raw 26-row
  channel table, a one-line readiness summary instead of four overlapping
  sample counters, and a plain-language Report tab instead of a numeric
  Score/Confidence/Outflow table. A single **Advanced** toggle in the header
  (persisted across restarts) reveals every raw number, ML hyperparameter and
  file path for anyone who wants it. Nothing is removed — it's collapsed, not
  hidden, so the app stays fully transparent about what it collects while not
  overwhelming a first-time user.
- **Data at rest is now encrypted.** The trained model and its checkpoints are
  protected with Windows DPAPI (bound to your Windows account), and are stored
  on an EFS-encrypted folder where available. A prior training run that
  crashed or was interrupted no longer leaves a plaintext model fragment
  (`.train_scratch`) behind — this is fixed with a guaranteed cleanup, not a
  best-effort one.
- **Code-signed.** Both `RCA-Desktop.exe` and `RCA-Collector.exe` are now
  digitally signed (self-signed certificate + RFC 3161 timestamp), so the
  published SHA256 checksum plus `signtool verify` gives you a chain of trust
  from this build to your machine, even though SmartScreen still shows its
  generic warning (see above).
- Clearer error messages if Windows account credentials change and the
  encrypted model can no longer be read (you're told to retrain, instead of
  seeing a raw Windows API error).

## What it records

Every 30 seconds: CPU, memory, disk, network, battery and GPU readings, the
name of the application currently in focus, and how long since you touched the
keyboard. Every 5 minutes — and every 30 seconds while the machine is busy —
the names of the busiest programs. As they occur: a fixed list of Windows Event
Log entries such as crashes and unexpected shutdowns.

**Never recorded:** window titles, page addresses, keystrokes, file contents,
browsing history, or the text of documents.

Everything is stored at `%LOCALAPPDATA%\RCA`, and the model/checkpoints are
now encrypted at rest (see above).

**You can stop it.** *Captured Data → Pause collection* (or the simplified
status card) halts recording within about 30 seconds and it stays stopped
across restarts until you resume.

## Removing it

Add / Remove Programs, or `RCA-Collector.exe uninstall`, reverses the logon
entry, Start menu shortcut and Add/Remove entry, and stops collection while
keeping what was already collected. `RCA-Collector.exe delete-all-data` erases
the database, model, reports and logs as well.

## Known limitations

- **Unsigned by a trusted CA.** Every user still meets a SmartScreen warning —
  the self-signed certificate proves integrity, not identity trusted by
  Windows. Mitigated by the published checksum and `signtool verify`.
- **Updates are opt-in and manual.** Upgrading means fetching the new ZIP
  yourself; nothing auto-downloads or auto-installs.
- **No crash reporting.** `desktop.log` never leaves your machine.
- **Tested on one machine.** Every measurement in the documentation comes from
  a single Windows 11 host.
- **It often declines to explain.** Measured across real incidents, roughly
  one in six produced a supported causal chain. The application says so rather
  than inventing an answer.

`docs/IMPLEMENTATION_PAPER.md` in the repository documents how it works, what
was measured, and where the measurements contradicted the design.
